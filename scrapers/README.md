## 쿠팡 수집 연구 노트

### 차단 원인
- **Akamai Bot Manager**: TLS fingerprint, JavaScript challenge, behavioral analysis
- Selenium/Playwright 기본 설정으로는 거의 확실히 차단됨
- IP 기반 차단 (데이터센터 IP 등)

### 실제 가능한 접근법

#### 1. 상업 스크래핑 API (추천)
- **Bright Data**: Web Scraper API, 쿠팡 전용 스크래퍼 제공
- **Apify**: Coupang Scraper Actor (1,000개당 ~$2)
- **Thunderbit**: AI 기반 크롬 확장

#### 2. 레시덴셜 프록시 + 브라우저 자동화
- 실제 한국 주거 IP 필요
- 브라우저 프로파일 유지 (쿠키, 로컬스토리지)
- 비용: 월 $50~200+

#### 3. 수동/반자동 수집
- 브라우저 확장으로 가격 수동 기록
- 정기적인 알림 기반 수집

### 쿠팡 가격 추적 서비스 참고
- lowchart.com: 쿠팡 가격 추이 추적
- geniealert.co.kr: 쿠팡 생활용품 가격 추이
- 이러한 서비스를 참고하여 데이터 소스 파악
